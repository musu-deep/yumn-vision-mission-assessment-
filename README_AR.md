# ورشة بناء الرؤية والرسالة والقيم لجمعية يُمن الصحية

منصة مؤسسية تفاعلية لإدارة مشاركة مجتمع الدراسة وفريق إعداد الإطار الاستراتيجي، وتشمل:

- بناء الرؤية والرسالة عبر قمع تفاعلي قابل للكتابة.
- اختيار القيم وبناء مصفوفة السلوك ومؤشرات التطبيق.
- مشاركة المستخدمين في التحليل الرباعي وتحليل PESTLE.
- فصل الصياغات النهائية عن مصفوفة القيم.
- تقييد الصياغات النهائية والمحاور التخصصية حسب الصلاحية.
- حفظ الاستجابات تلقائيًا في PostgreSQL مع نسخة مؤقتة داخل المتصفح.
- حساب مستقل لكل مشارك برقم الجوال ورمز شخصي مشفّر.
- جلسات دخول موقعة داخل Cookie آمنة لا يمكن لبرمجيات المتصفح قراءتها.
- منع المشارك من فتح أو تعديل استجابة مشارك آخر.
- قفل مؤقت بعد تكرار محاولات الدخول الخاطئة وحدود لطلبات الحفظ.
- لوحة إدارة مركزية للحسابات والاستجابات وإعادة ضبط الرمز الشخصي.
- تكامل اختياري مع واتساب عبر Webhook أو رابط المحادثة المباشر.

## متغيرات Render المطلوبة

```env
DATABASE_URL=postgresql+psycopg://...
API_KEY=قيمة_عشوائية_طويلة
ALLOWED_ORIGINS=https://اسم-الخدمة.onrender.com
ADMIN_USERNAME=admin
ADMIN_PASSWORD=كلمة_مرور_إدارية_قوية
STUDY_ACCESS_CODE=رمز_دعوة_مجتمع_الدراسة
SESSION_HOURS=12
WHATSAPP_WEBHOOK_URL=
```

`STUDY_ACCESS_CODE` اختياري تقنيًا، لكنه موصى به عند توزيع الرابط على مجموعة محددة. لا تُرفع القيم الحقيقية إلى GitHub.

## فحص الجاهزية

بعد النشر افتح `/health`. الجاهزية المكتملة تظهر هكذا:

```json
{
  "status": "ok",
  "service": "yumn-platform",
  "database": "ok",
  "auth": "session-cookie",
  "security": "ok"
}
```

## اختبار ما قبل التوزيع

1. إنشاء مشاركة تجريبية من هاتف برمز شخصي من 6 أرقام.
2. تعبئة حقل وحفظه حتى تظهر رسالة الحفظ في قاعدة البيانات.
3. تسجيل الخروج ثم الدخول من متصفح آخر بالرقم والرمز نفسيهما.
4. التأكد من استعادة الإجابة السابقة.
5. تجربة رقم صحيح مع رمز خاطئ والتأكد من رفض الدخول.
6. دخول الإدارة والتأكد من ظهور الحساب والاستجابة في اللوحة المركزية.
