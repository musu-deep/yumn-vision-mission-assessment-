# منصة إعداد الرؤية والرسالة والقيم لجمعية يُمن الصحية

منصة مؤسسية تفاعلية لإدارة مشاركة فريق إعداد الخطة والإطار الاستراتيجي، وتشمل:

- بناء الرؤية والرسالة عبر قمع تفاعلي قابل للكتابة.
- اختيار القيم وبناء مصفوفة السلوك ومؤشرات التطبيق.
- مشاركة المستخدمين في التحليل الرباعي وتحليل PESTLE.
- فصل الصياغات النهائية عن مصفوفة القيم.
- تقييد الصياغات النهائية والمحاور التخصصية برموز وصول.
- صلاحيات لمدير النظام وفريق المستشار والمشاركين.
- حفظ الاستجابات ومزامنتها مع قاعدة بيانات PostgreSQL.
- تكامل اختياري مع واتساب عبر Webhook أو رابط المحادثة المباشر.

## التشغيل باستخدام Docker

1. انسخ ملف البيئة:

```bash
cp .env.example .env
```

2. عدّل `API_KEY` وكلمة مرور قاعدة البيانات وإعدادات النطاق.

3. شغّل المنصة:

```bash
docker compose up -d --build
```

4. افتح:

```text
http://localhost:8000
```

ينشئ `Dockerfile` ملف الواجهة تلقائيًا من الأجزاء المضغوطة الموجودة داخل مجلد `frontend`، ثم يشغّل الواجهة والخادم في خدمة واحدة.

## إعداد التكامل داخل المنصة

من حساب مدير النظام، افتح **التكامل والنشر** ثم أدخل:

- عنوان API: عنوان الخادم، مثل `http://localhost:8000`.
- رمز API: القيمة المحددة في `API_KEY`.
- Webhook واتساب عند استخدام مزود إرسال خارجي.

## نقاط API

- `GET /health`
- `POST /api/responses`
- `POST /api/sync`
- `GET /api/sync`
- `POST /api/whatsapp/send`
