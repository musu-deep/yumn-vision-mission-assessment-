# منصة إعداد الرؤية والرسالة والقيم لجمعية يُمن الصحية

منصة مؤسسية تفاعلية لإدارة مشاركة فريق إعداد الخطة والإطار الاستراتيجي، وتشمل:

- بناء الرؤية والرسالة عبر قمع تفاعلي قابل للكتابة.
- اختيار القيم وبناء مصفوفة السلوك ومؤشرات التطبيق.
- مشاركة المستخدمين في التحليل الرباعي وتحليل PESTLE.
- فصل الصياغات النهائية عن مصفوفة القيم.
- تقييد الصياغات النهائية والمحاور التخصصية برموز وصول.
- صلاحيات لمدير النظام وفريق المستشار والمشاركين.
- حفظ الاستجابات ومزامنتها مع قاعدة بيانات PostgreSQL.
- تكامل اختياري مع واتساب عبر Webhook أو رابط المحادثة المباشر.
